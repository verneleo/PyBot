# Кинопоиск Telegram Боd
Телеграм-бот для поиска случайных фильмов с использованием API Кинопоиска.
## Возможности
- Случайные рекомендации фильмов
- Выбор жанра через кнопки Telegram
- Отображение постера фильма
- Краткое описание
- Рейтинг Кинопоиска
- Год выхода
- Продолжительность фильма
- Страна производства
# Поддерживаемые жанры
- Комедия
- Драма
- Боевик
- Детектив
# Используемые технологии
- Python 3
- python-telegram-bot
- Requests
- API Кинопоиска
- dotenv
# Установка
## Клонируйте репозиторий:
- git clone <ссылка-на-репозиторий>
- cd PyBot
## Установите зависимости:
- pip install -r requirements.txt
## Создайте файл .env:
- BOT_TOKEN=ваш_токен_бота
- X-API-KEY=ваш_ключ_кинопоиска
## Запустите бота:
python main.py
# Структура проекта
main.py          - логика Telegram-бота
kinopoisk.py     - работа с API Кинопоиска
requirements.txt - зависимости
.env             - секретные данные
